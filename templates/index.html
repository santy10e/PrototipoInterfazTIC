Analizando la noticia…

Preprocesamiento del texto, vectorización TF-IDF y clasificación.

¿Cómo se obtiene este resultado?

El texto se limpia, se tokeniza y se eliminan las palabras vacías (NLTK). Después se transforma con TF-IDF, se seleccionan y normalizan las características y el modelo de regresión logística estima una probabilidad. Si esa probabilidad supera 0,70, la noticia se clasifica como falsa; en caso contrario, como verdadera.

El modelo no ofrece una explicación de qué partes del texto influyeron en la clasificación.

Ver la ficha técnica del modelo

Este resultado corresponde a una predicción automatizada basada en un modelo de Machine Learning. No constituye una verificación factual definitiva.

      Regla de decisión

      Cómo se convierte la probabilidad estimada en una clase.

      Verdadera Falsa
      00,701

      El modelo produce una puntuación que se transforma con la función sigmoide. Si el resultado es mayor que 0,70, la noticia se clasifica como falsa.

      Alcance y limitaciones

      • La clasificación es una predicción estadística, no una verificación periodística.
      • El modelo no indica qué palabras o frases determinaron el resultado.
      • La interfaz no muestra un porcentaje de confianza porque el servidor no lo devuelve.
      • Fue desarrollado para noticias de política en español; con otros temas o idiomas los resultados pueden no ser representativos.
